# SmartPark Edge — User Guide (static website)

End-user documentation in **English** and **Kiswahili**, with light/dark theme.

## Open locally

Double-click `index.html` or open it in any web browser.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Guide content and illustrations |
| `styles.css` | Layout, light/dark themes |
| `i18n.js` | English and Swahili translations |
| `app.js` | Language switch, theme toggle, navigation |

Language and theme choices are remembered in the browser.

## On the parking PC

After installing SmartPark from USB, open:

`%LOCALAPPDATA%\Programs\SmartPark Edge\documentation\index.html`
